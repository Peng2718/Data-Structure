我研究了list，发现pushback是将元素加到尾部，而pushfront是从头部开始加，且都是增加元素操作，即不会改变原有元素，而是增加元素

又熟悉了一下队列quene，原来队列都是对首尾进行操作的，通过push加入元素，通过front和back查看首尾元素，通过empty判断是否为空，通过pop放出头部也就是最先加入的元素
